# TradingView 인기 지표 분석 — 매수/매도 타이밍 관점

> 코드 구현: `tvlab/indicators.py` (지표) · `tvlab/signals.py` (규칙) · `tvlab/ta.py` (Pine `ta.*` 재현)

## 0. 먼저 알아둘 것: 지표는 4종류밖에 없다

거의 모든 지표는 OHLCV 를 아래 4가지 중 하나로 가공한다. 같은 분류의 지표 여러 개를
겹쳐 쓰면 **같은 정보를 여러 번 세는 것**(다중공선성)일 뿐 확률이 올라가지 않는다.
조합할 때는 **서로 다른 분류**에서 하나씩 고르는 게 원칙이다.

| 분류 | 묻는 질문 | 대표 지표 | 매수 신호의 성격 |
|---|---|---|---|
| 추세 | 방향이 있는가? | MA/EMA, Supertrend, DMI/ADX, 일목, PSAR, 돈치안 | 늦게 사고 길게 먹음 (승률↓, 손익비↑) |
| 모멘텀/오실레이터 | 너무 많이/빨리 움직였나? | RSI, Stoch, StochRSI, MACD, CCI, %R | 일찍 사고 짧게 먹음 (승률↑, 손익비↓) |
| 변동성 | 움직임의 크기는? | 볼린저, 켈트너, ATR, 돈치안 폭 | 스퀴즈→돌파, 밴드 이탈→회귀 |
| 거래량 | 돈이 따라붙었나? | Volume, OBV, MFI, VWAP | 단독보단 필터로 |

**추세 신호와 평균회귀 신호는 정반대 가정**이다. "하단밴드 터치 매수"(평균회귀)와 "돈치안
돌파 매수"(추세추종)를 같은 종목에 동시에 쓰면 서로 상쇄된다. 먼저 시장/종목이 어느 체제인지
(ADX, 볼린저 폭 백분위 등)를 판별하고 그에 맞는 계열을 쓰는 게 실무 관행이다.

## 1. TradingView 에서 가장 많이 쓰이는 지표 (내장 기본값 기준)

TradingView 커뮤니티/내장 지표 사용 빈도 상위권은 대체로 다음과 같다(공식 순위 통계는
공개되지 않아 경험적 순서). 모두 `tvlab` 에 TradingView 기본 파라미터로 구현돼 있다.

| 지표 | Pine 수식 (기본값) | 대표 매수 규칙 | 함정 |
|---|---|---|---|
| **이동평균 (SMA/EMA)** | `ta.sma(close,n)`, `ta.ema(close,n)` — EMA 는 SMA 로 시드 | 골든크로스, 정배열 전환, 가격의 MA 돌파 | 크로스는 후행. 횡보장에서 휩쏘 연속 |
| **RSI** (Wilder, 1978) | `ta.rma` 로 상승/하락 평균, 14 | 30 상향 돌파, 상승추세 중 40~50 지지 | 강한 추세에선 과매수가 지속 → 역추세 매도 금지 |
| **MACD** (Appel) | `ema(12)-ema(26)`, 시그널 `ema(9)` | 시그널 상향교차(특히 0선 아래) | 두 EMA 차이라 사실상 추세지표. 지연 큼 |
| **볼린저 밴드** | `sma(close,20) ± 2·stdev(close,20)` — **모표준편차** | 하단 재진입(회귀), 스퀴즈 후 상단 돌파(추세) | 같은 지표로 정반대 전략 둘 다 가능 — 체제 판별 필수 |
| **Stochastic / StochRSI** | `%K=100·(C−LL)/(HH−LL)`, 14·1·3 / RSI 에 스토캐스틱 | 20 아래에서 %K↑%D | StochRSI 는 매우 시끄러움 |
| **Supertrend** | `hl2 ± 3·atr(10)` 래칫 | 방향 전환(−1) | 변동성 낮은 장에서 잦은 플립 |
| **일목균형표** | 전환 9, 기준 26, 선행B 52, 26봉 선행 | 전환선>기준선 교차 + 구름 위 | **구름은 26봉 앞으로 그려짐** → 백테스트 시 시프트 주의 |
| **DMI / ADX** (Wilder) | `rma` 기반 +DI/−DI, ADX 14 | +DI↑−DI 교차 & ADX>20 | ADX 는 방향이 아닌 '세기' |
| **VWAP** | 세션 누적 `Σ(hlc3·V)/ΣV` | 장중 VWAP 회복 | 일봉 이상에선 의미 약함 |
| **OBV / MFI** | 거래량 누적 / 거래량 가중 RSI | 가격-OBV 다이버전스, MFI 20 상향 | 단독 신호력 약함 → 필터용 |
| **돈치안 채널** | `highest(high,n)`, `lowest(low,n)` | n봉 신고가 돌파 (터틀 20/55) | 승률 30~40% 가 정상. 손익비로 먹는 전략 |
| **켈트너 채널** | `ema(20) ± 2·atr(10)` | 볼린저가 켈트너 안으로 → 스퀴즈 | |
| **Parabolic SAR** | AF 0.02→0.2 | 점이 가격 아래로 전환 | 횡보장 최악 |
| **CCI / Williams %R** | `(hlc3−sma)/(0.015·meandev)` / `−100·(HH−C)/(HH−LL)` | −100 / −80 상향 | RSI 류와 정보가 겹침 |

### 수식 재현에서 자주 틀리는 부분 (TradingView 와 값이 안 맞을 때)

1. **표준편차**: Pine `ta.stdev` 는 N 으로 나눈다. pandas `.std()` 는 N−1 → 밴드가 √(N/(N−1)) 배 넓어짐.
2. **EMA/RMA 시드**: Pine 은 첫 값을 SMA 로. pandas `ewm` 은 첫 종가로.
3. **RMA vs EMA**: RSI·ATR·ADX 는 Wilder RMA(α=1/n). EMA(α=2/(n+1)) 로 바꾸면 값이 크게 달라진다.
4. **피벗(저점/고점 신호)**: `ta.pivotlow(5,5)` 는 저점 **5봉 뒤** 확정된다. 차트엔 저점 봉에
   그려지지만(`offset=-right`), 실제로 알 수 있는 건 5봉 뒤다. 이걸 무시하면 백테스트 승률이
   비현실적으로 높게 나온다. 사용자 지표의 `plot_16/17` 저점/고점 신호가 이 유형일 가능성이 높다.
5. **밴드형 지표 역추적**: 상·하단을 따로 맞추지 말고 **중심=(상+하)/2, 반폭=(상−하)/2** 로
   분해하면 중심은 MA, 반폭은 k·(stdev|ATR|range) 로 각각 독립적으로 맞는다. `tvlab.fit.fit_band`
   가 이 탐색을 자동화한다 (sma(close,30) ± 2·stdev(close,30) 사례가 테스트에 포함됨).

## 2. Ed Seykota 의 기술적 도구 — 추세추종 관점

> 참고: 요청하신 `meta-formula.com` PDF 는 이 작업 환경의 네트워크 정책으로 내려받지 못했다.
> 아래는 Seykota 가 공개적으로 설명해 온 TSP(Trading System Project) 계열 도구의 일반적인
> 내용이며, PDF 의 정확한 파라미터와는 다를 수 있다. PDF 를 저장소에 넣어주면 맞춰서 수정 가능.

Seykota 의 핵심은 지표보다 **규칙과 리스크**다.

* **EMA 교차 시스템**: 빠른 EMA 가 느린 EMA 를 상향 돌파하면 매수, 하향 돌파하면 청산/매도.
  (`signals.py` 의 `ema_cross_15_150` — 파라미터는 예시)
* **채널 돌파 (돈치안)**: n봉 최고가 돌파 매수, m봉 최저가 이탈 청산 (m<n).
* **볼린저 돌파**: 상단 돌파 진입, 중심선 복귀 청산 — 평균회귀가 아니라 **추세추종**으로 사용.
* **ATR 기반 리스크(heat)**: 손절 폭을 ATR 배수로 잡고, 손절 시 계좌의 일정 %(예: 1%)만 잃도록
  포지션 크기를 정한다. 승률이 아니라 **손익비와 생존**이 수익을 만든다.
* 메시지: "추세는 끝날 때까지 친구다." 추세추종은 **승률 35~45%, 큰 이익 몇 번**이 정상이다.
  그러므로 이 계열을 *승률*로만 평가하면 항상 나빠 보인다 → `evaluate.backtest` 로 손익비·MDD 를 같이 봐야 한다.

## 3. "확률 높은 매수 타이밍"을 검증하는 법

`tvlab.evaluate.event_study` 가 아래를 자동으로 한다.

1. **기저율과 비교**: "신호 후 10일 수익 +1%" 는 의미 없다. 그 기간 아무 날이나 샀을 때
   평균이 +1.2% 였다면 그 신호는 *오히려 나쁜* 신호다. → `edge = mean − base_mean`
2. **진입은 다음 봉 시가**: 신호 봉 종가에서 체결된다고 가정하면 낙관 편향.
3. **겹침 제거**: 연속 신호를 h봉 쿨다운으로 1개만 남겨 표본 수 부풀리기 방지.
4. **전/후반 분할(IS/OOS)**: 앞 60% 에서 좋고 뒤 40% 에서도 좋아야 `consistent`.
5. **다중검정 보정(BH q-value)**: 22개 신호 × 3개 보유기간 = 66번 시험하면 운으로 3개쯤은
   p<0.05 가 나온다. 합성 랜덤워크 데모에서도 실제로 2개가 "전/후반 모두 우수"로 나왔다.
   그래서 `robust = consistent & q<0.10` 으로 둔다.
6. **비용**: 국내 주식 왕복 0.2~0.3%(수수료+거래세+슬리피지). 엣지가 이보다 작으면 무의미.

그 다음 단계로 `tvlab.model.walk_forward` 가 여러 지표를 스케일 무관 특징으로 바꿔
로지스틱 회귀로 **P(h봉 뒤 상승)** 을 추정한다. 판단 기준은 OOS **AUC > 0.55 가 안정적으로**
나오는지, 그리고 **예측확률 5분위별 실제 적중률이 단조 증가**하는지(보정 곡선)다.
랜덤워크에선 AUC ≈ 0.5 로 나와야 정상이며, 실제 데이터에서 0.52~0.55 만 나와도 꽤 좋은 편이다.
